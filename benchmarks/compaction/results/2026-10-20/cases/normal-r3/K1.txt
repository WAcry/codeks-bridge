## Established behavior / constraints

- Defaults: 4 workers, 4 MiB chunks, **4 extra retries = 5 attempts**.
- Concurrency CLI range 1–16; effective `min(requested, server maximum_parallel_parts)` (requested 2 remains 2).
- Authenticated capability discovery required before begin, protocol exactly 3; malformed discovery fails without guessed defaults.
- Dry-run scans totals but does **zero network calls**, no `.driftship` creation, may display requested concurrency.
- Global request/part bound across all files; no per-file worker explosion. Pending part iterator is lazy.
- Resume flag is **`--resume=on|off` default on**; reject `verify` and old `--no-resume`.
- Journal `.driftship/resume-v1.json` inside source.
- `resume=off` ignores old local state, starts fresh locally, **never deletes/aborts remote sessions**.
- Durable journal: serialized mutations; temp 0600, parent 0700, fsync temp, rename, fsync directory. Write failure stops work, no success.
- Identity: full SHA-256 + size + nanosecond mtime (+ matching chunk size).
- Remote identity mismatch = `session_mismatch`, no replacement. Only missing/expired remote sessions restart automatically.
- Only exact idempotent PUT parts retry. Begin/complete never automatically retry.
- Lost part response replay safe; confirmed bytes count unique parts, not traffic.
- Ambiguous completion socket failure: one GET status, matching complete receipt accepted; GET failure surfaced, next invocation resumes. No duplicate POST.
- Cancellation aborts requests, stops scheduling, settles queued journal updates, exit 130.
- Exit codes: 0 success, 1 server/transport/ordinary I/O incl permission/checksum failures, 2 usage/config, 3 invalid/mismatched resume state incl `session_mismatch`, 130 interruption.
- Reject URL query, fragment, userinfo; only trailing slash normalization. Preserve tenant prefix and Unicode spelling; percent literal escaped correctly.
- Auth only `DRIFTSHIP_TOKEN`; never journal/output/URL. Errors must not echo supplied URL/token. Redirects rejected.
- Scan excludes `.git`, `.driftship`, symlinks, FIFOs/devices; includes ordinary dotfiles, never executes hooks or filenames.
- Empty files begin/complete zero parts.
- Users must not modify source during upload; detected changes fail. No atomic snapshots/locks/watchers/COW.
- JSON events retain `type`, one UUID `run_id` per invocation on all events.
- Completion fields: `files`, `bytes`, `uploaded_bytes`, `resumed_bytes`.
