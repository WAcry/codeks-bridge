2. Key Technical Concepts

- TypeScript ESM CLI, Node >=22, native fetch/fs/crypto/http/test APIs.
- No runtime dependencies; dev dependencies TypeScript ^5.9 and @types/node ^22.
- Protocol revision 3 capability discovery, authenticated before begin.
- Global bounded concurrency, lazy pending-part iteration.
- Chunked uploads with SHA-256 per part and whole-file checksum.
- Idempotent exact part replay after socket failure.
- Durable atomic journal replacement: serialize mutations, write temporary file, fsync file, rename, fsync directory.
- Journal permissions: parent 0700, file 0600.
- Full identity verification before resume and final fingerprint before completion.
- Strict receipt and part-list validation.
- Retry-After parsing, jittered exponential fallback, abortable sleep.
- JSON lines event stream with stable type discriminator and invocation UUID.
- Local fake HTTP server fault injection and stress testing.
- Exit codes:
  - 0 success
  - 1 transport/server or ordinary local I/O
  - 2 usage/configuration
  - 3 invalid or mismatched local resume state, including session_mismatch
  - 130 interruption

Server protocol constraints read from docs/server-protocol.md:

- Preserve entire tenant base URL path.
- Escape individual path segments; literal percent becomes %25; preserve Unicode spelling.
- GET capabilities returns protocol 3; minimum_chunk_bytes 1048576; maximum_chunk_bytes 16777216; preferred_chunk_bytes 4194304; maximum_parallel_parts 4; checksums ["sha256"].
- POST uploads takes {path,size,chunk_bytes,sha256}; returns upload_id, expires_at, committed_parts.
- Upload IDs are opaque, case-sensitive, never local paths.
- PUT uploads/{id}/parts/{part}: one-based; Content-Length and X-Part-SHA256; only last part may be short.
- Exact replay succeeds 204; checksum mismatch 422; conflicting existing body 409.
- GET uploads/{id}: open|complete|expired plus part_size,file_size,file_sha256, unordered parts; complete includes receipt. Missing session 404.
- POST complete takes sorted parts and whole-file hash; atomic commit.
- Retryable PUT statuses: 408,429,500,502,503,504. 401/403 permanent.
- Empty files begin/complete with no parts and SHA-256 of empty bytes.
- Redirects unsupported for authenticated writes.
- Consume complete JSON bodies, bounded by service to 1 MiB; responses may arrive incrementally.
- Proxy idle timeout 90 seconds.

    private path:string;
    private state:Journal;
    private pending:Promise<void>=Promise.resolve();
    private failed:unknown;
    constructor(path:string,state:Journal){this.path=path;this.state=state;}
    update(change:(state:Journal)=>void):Promise<void> {
      const operation=this.pending.then(async()=>{
        if(this.failed!==undefined)throw this.failed;
        change(this.state);
        await writeJournal(this.path,this.state);
      });
      this.pending=operation.catch(error=>{this.failed=error;});
      return operation;
    }
    async settled(){
      await this.pending;
      if(this.failed!==undefined)throw this.failed;
    }
  }

  export function retryDelay(header:string|null,now:number):number|undefined {
    if(!header)return undefined;
    const seconds=Number(header);
    if(Number.isFinite(seconds)&&seconds>=0)return seconds*1000;
    const date=Date.parse(header);
    if(!Number.isNaN(date))return Math.max(0,date-now);
    return undefined;
  }
  export async function retry<T>(
    operation:(attempt:number)=>Promise<T>,
    classify:(e:unknown)=>{retry:boolean;after?:string},
    options:RetryOptions
  ):Promise<T> {
    const now=options.now??Date.now, random=options.random??Math.random;
    const sleep=options.sleep??((ms,signal)=>setTimeout(ms,undefined,{signal}));
    for(let attempt=0;;attempt++) {
      options.signal.throwIfAborted();
      try {return await operation(attempt);}
      catch(error) {
        const decision=classify(error);
        if(!decision.retry||attempt>=options.retries)throw error;
        const after=retryDelay(decision.after??null,now());
        const base=Math.min(30000,500*2**attempt);
        const delay=after??Math.floor(base*(0.5+random()*0.5));
        options.onRetry?.(attempt+1,delay);
        await sleep(delay,options.signal);
      }
    }
  }
