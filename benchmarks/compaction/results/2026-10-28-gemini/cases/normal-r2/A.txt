3. **Key Findings**
   - From `node scripts/review-final-diff.ts` and user instructions:
     - **R1 (Must Fix in `src/retry.ts` & tests)**: `retryDelay("-1", now)` fails `seconds >= 0` (`Number("-1")` is `-1`), then falls through to `Date.parse("-1")`, which V8 parses as a past date, returning `Math.max(0, date - now) === 0` ms instead of `undefined`! The test `retry-negative` in `integration/generated/protocol-03.test.ts` only checked `Number.isFinite(delay)`, missing the zero-delay bug. `retryDelay` must use a strict nonnegative delta-seconds grammar (`/^\d+$/`) and strict HTTP-date parsing so negative/numeric strings return `undefined` and fall back to local backoff.
     - **R2 (Must Fix in `src/push.ts` & tests)**: In `src/push.ts`, when resuming a file where `GET uploads/{id}` returns `status.state === 'complete'`, the fast path validates `status.receipt` before calling `validateSession(status, saved)`. `validateSession` (`status.file_size`, `status.file_sha256`, `status.part_size`) only runs on the `status.state === 'open'` branch. Moving `validateSession(status, saved)` before both `complete` and `open` branches ensures a mismatched completed session raises `session_mismatch` (exit code 3).
     - **R3 (Must Fix in `README.md`)**: The first example in `README.md` still says `--no-resume`; replace it with `--resume=off`.
     - **R6 & Follow-ups (`docs/development-notes.md` / `docs/json-events.md`)**: Document that initial CLI argument parse errors occur before `--json` is known and output plain text to `stderr`. Record follow-ups in `docs/development-notes.md` (Windows directory-fsync/rename durability unvalidated, missing real storage-service smoke test requiring dedicated test tenant/credentials, file descriptor reuse for source-change race reduction, and lazy session creation for very large file trees).

4. **Errors & Fixes**
   - *Concurrent journal lost updates (`expected parts [1,2], observed [2]`)*: Fixed by serializing state mutations and disk writes through `JournalStore` (`src/journal-store.ts`) and syncing the parent directory after `rename`.
   - *Silent query stripping on destination URL*: Fixed `validateDestination` in `src/path.ts` to reject URL userinfo, query strings, and fragments before normalizing the trailing slash.
   - *Duplicate `complete` POST on already-completed session & unhandled socket reset on `complete`*: Fixed `src/push.ts` to short-circuit on `status.state === 'complete'` and `src/complete.ts` to perform one `GET uploads/{id}` status check when `POST .../complete` throws a network `TypeError`.
   - *Typecheck errors in `src/journal-store.ts`, `src/transport.ts`, `src/cli.ts`*: Fixed promise catch return type (`{ this.failed = error; }`), passed `new Uint8Array(body)` to `fetch`, and narrowed `error instanceof CliError` before reading `.code`.
   - *Exit code 1 instead of 3 on `destination_mismatch` & unsettled journal write on `SIGINT`*: Added `src/exit-code.ts` mapping resume/session mismatches to `3` and `SIGINT` to `130`; wrapped `parallel(...)` in `try/finally { await store.settled(); }` in `src/push.ts`.
