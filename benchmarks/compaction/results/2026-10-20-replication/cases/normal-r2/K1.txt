## Requirements and agreed behavior

- Command stays `driftship push <directory> --to <url>`.
- Defaults four workers,4 MiB chunks, four retries = four extra attempts/five total.
- `--concurrency` range1–16, effective min(requested, server max); requested2 stays2.
- Authenticated discovery `GET capabilities`, protocol must3, valid constraints, SHA256 supported; malformed discovery fails before begin; no guessed defaults.
- Server documented min1 MiB, max16 MiB, preferred4 MiB, max parallel4.
- Global request bound across push; lazy pending parts, not one worker/file or every-part materialization.
- Resume default on. Only `--resume=on|off`; reject `verify` and old `--no-resume`.
- Journal source `.driftship/resume-v1.json`. Off ignores old local state; never deletes/aborts remote sessions.
- Durable journal serialized mutations via promise queue, temporary file0600, parent0700, fsync file, rename, fsync directory. Failures propagate; queued writes settle on cancel/failure.
- Identity full SHA256,size,nanosecond mtime. Full reread acceptable.
- Remote status `file_size`, `file_sha256`, `part_size` must match before resumed parts **and completed receipt**; mismatch `session_mismatch`, no silent restart.
- Only missing404/expired sessions auto restart; local changed identity creates new session.
- Only idempotent PUT part retries; begin/complete never auto retry.
- Ambiguous connection loss on complete permits one GET status; matching complete receipt succeeds; GET failure returns its own error. No duplicate complete POST.
- Confirm uploaded unique bytes, not retransmission traffic; resumed vs uploaded mutually exclusive. Complete JSON fields `files`, `bytes`, `uploaded_bytes`, `resumed_bytes`.
- All JSON events `type` discriminator and one UUID `run_id` generated once/invocation.
- dry-run scanning allowed, zero network (including discovery), no `.driftship`.
- SIGINT abort requests, stops new work, settles queued journal writes, exit130.
- Exit0 success;1 transport/server/ordinary I/O (including permission and server checksum);2 usage/config;3 invalid/mismatched local resume state including `session_mismatch`;130 interruption.
- Reject URL query/fragment/userinfo; only trailing slash normalized. Preserve tenant prefix, escaped segments, literal percent, exact Unicode spelling. Errors never echo supplied URL/token.
- Token only `DRIFTSHIP_TOKEN`; no tokens in journals/output/request snapshots. Reject redirects.
- Exclude `.git`/`.driftship`; skip symlinks/FIFOs/devices, ordinary dotfiles included; never execute filenames/hooks.
- Empty begin/complete zero parts, empty SHA256; receipt counts completed file.
- Users must not modify source during upload; detected changes fail. No snapshots,locks,COW,watchers requested.

```ts
import { setTimeout } from 'node:timers/promises';
export interface RetryOptions { retries:number; signal:AbortSignal; now?:()=>number; random?:()=>number; sleep?:(ms:number,signal:AbortSignal)=>Promise<void>; onRetry?:(attempt:number,delayMs:number)=>void; }
export function retryDelay(header:string|null,now:number):number|undefined {
  if(!header)return undefined;
  const seconds=Number(header);
  if(Number.isFinite(seconds)&&seconds>=0)return seconds*1000;
  const date=Date.parse(header);
  if(!Number.isNaN(date))return Math.max(0,date-now);
  return undefined;
}
export async function retry<T>(operation:(attempt:number)=>Promise<T>, classify:(e:unknown)=>{retry:boolean;after?:string},options:RetryOptions):Promise<T> {
  const now=options.now??Date.now, random=options.random??Math.random;
  const sleep=options.sleep??((ms,signal)=>setTimeout(ms,undefined,{signal}));
  for(let attempt=0;;attempt++) {
    options.signal.throwIfAborted();
    try {return await operation(attempt);}
    catch(error) {
      const decision=classify(error);
      if(!decision.retry||attempt>=options.retries)throw error;
      const after=retryDelay(decision.after??null,now());
      const base=Math.min(30000,500*2**attempt);
      const delay=after??Math.floor(base*(0.5+random()*0.5));
      options.onRetry?.(attempt+1,delay);
      await sleep(delay,options.signal);
    }
  }
}
```
