### Required behavior and decisions

- Defaults: 4 workers, 4 MiB chunks, 4 retries = **5 attempts**.
- Concurrency option range 1–16; effective concurrency `min(requested, server maximum_parallel_parts)`, so requested 2 stays 2.
- Authenticated capabilities discovery before begin. Protocol must be 3; malformed discovery fails without guessed defaults. Validate chunk constraints and SHA256 support.
- Global request/part concurrency bound, not separate pools per file. Lazy pending-parts iterator replaces materialized jobs.
- Only idempotent PUT parts retry. Begin/complete never automatically retry.
- After ambiguous complete connection failure, allow exactly one GET status. If it fails return GET error; next invocation resumes. Complete receipt must match path, size, hash.
- Lost persisted part response replays identical bytes safely.
- Empty files begin/complete with zero parts.
- Resume default on; CLI **`--resume=on|off`**. Reject `verify` for now. **No `--no-resume` alias**.
- `--resume=off` starts fresh locally, never aborts/deletes remote sessions.
- Journal `.driftship/resume-v1.json` within source. Serialized mutation queue; temp mode0600, parent0700, file fsync, rename, directory fsync. Fail on I/O errors, stop scheduling; settle queued writes on cancellation.
- Resume identity full SHA256 + size + nanosecond mtime; full read cost accepted.
- Validate remote `file_size`, `file_sha256`, `part_size` for resumed sessions. Mismatch `session_mismatch`, never silently replace. Only missing/expired remote state restarts automatically (changed local fingerprint also starts fresh).
- Reject URL query, fragment, userinfo. Only normalize trailing slash; preserve tenant prefix. Never echo supplied URL/token in errors. Auth only `DRIFTSHIP_TOKEN`; reject redirects.
- Dry-run zero network, zero `.driftship` creation; scanning totals allowed, display requested concurrency.
- JSON stdout objects keep `type` discriminator, each with same UUID `run_id` generated once per invocation. Completion fields `files`, `bytes`, `uploaded_bytes`, `resumed_bytes`. Confirmed unique bytes exclude replay traffic.
- Human progress stderr, completion stdout.
- Exit codes: 0 success; 1 transport/server/ordinary local I/O (incl permission errors and server checksum errors); 2 usage/config; 3 invalid/mismatched local resume state incl session_mismatch; 130 cancellation.
- Skip `.git`, `.driftship`, symlinks, FIFOs/devices. Preserve literal filenames and distinct Unicode forms; never run hooks/shell filenames.
- Source must not change during upload; detected changes fail. Snapshots, locks, COW, watchers out of scope.
- Windows durability unvalidated; directory-fsync rejection is I/O failure.

import { setTimeout } from 'node:timers/promises';
export interface RetryOptions { retries:number; signal:AbortSignal; now?:()=>number; random?:()=>number; sleep?:(ms:number,signal:AbortSignal)=>Promise<void>; onRetry?:(attempt:number,delayMs:number)=>void; }
export function retryDelay(header:string|null,now:number):number|undefined {
  if(!header)return undefined;
  const seconds=Number(header);
  if(Number.isFinite(seconds)&&seconds>=0)return seconds*1000;
  const date=Date.parse(header);
  if(!Number.isNaN(date))return Math.max(0,date-now);
  return undefined;
}
export async function retry<T>(operation:(attempt:number)=>Promise<T>, classify:(e:unknown)=>{retry:boolean;after?:string},options:RetryOptions):Promise<T> {
  const now=options.now??Date.now, random=options.random??Math.random;
  const sleep=options.sleep??((ms,signal)=>setTimeout(ms,undefined,{signal}));
  for(let attempt=0;;attempt++) {
    options.signal.throwIfAborted();
    try {return await operation(attempt);}
    catch(error) {
      const decision=classify(error);
      if(!decision.retry||attempt>=options.retries)throw error;
      const after=retryDelay(decision.after??null,now());
      const base=Math.min(30000,500*2**attempt);
      const delay=after??Math.floor(base*(0.5+random()*0.5));
      options.onRetry?.(attempt+1,delay);
      await sleep(delay,options.signal);
    }
  }
}
