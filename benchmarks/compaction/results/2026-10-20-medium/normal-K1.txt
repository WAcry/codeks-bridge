## Critical implementation and constraints

### Settings and discovery

- Default workers 4, chunks 4 MiB, retries 4 **extra** attempts (5 total).
- User concurrency range 1–16; effective `min(requested, server.maximum_parallel_parts)`. Requested 2 remains 2.
- Discover authenticated `GET capabilities`, require protocol 3 and valid limits/checksum support before begin; no guessed defaults.
- Dry-run scans totals, **zero network calls and no `.driftship` creation**, can show requested concurrency.
- Global bound across files, no worker per file. Pending parts now lazy iterator rather than flatMap.
- Protocol docs: `docs/server-protocol.md`; operational docs `docs/operational-constraints.md`.

### URLs/auth/security

- Token solely from `DRIFTSHIP_TOKEN`; never serialize/output URL credentials, tokens, raw remote bodies.
- Reject query, fragment, URL userinfo. Only trailing slash normalized; preserve tenant base path.
- Object names use per-segment escaping; percent literal, no Unicode normalization.
- Reject redirects.
- `.git`, `.driftship` excluded; skip symlinks/FIFOs/devices, ordinary dotfiles included. Never execute source hooks/shell filenames.

### Resume/journal

- `.driftship/resume-v1.json` under source.
- `--resume=on|off`, default on, reject `verify` and old `--no-resume`.
- Off starts fresh locally, never delete/abort remote sessions.
- Identity = full SHA-256 + size + nanosecond mtime + chunk size.
- Durable writes: serial mutation queue, temp file mode0600, parent0700, file fsync, rename, directory fsync. Errors halt new work.
- Validate JSON shape/version; bad state preserved.
- Remote status identity fields `file_size`, `file_sha256`, `part_size` must match or `session_mismatch` (exit3).
- Only missing404/expired remote state automatically restarts; inconsistent existing state fails.
- Full hashes before reuse and before completion; detected changes fail.
- Users must not modify source. Snapshot/locks/CoW/watchers out of scope; documented verification-to-complete race.

### Requests/retries/recovery

- Only idempotent exact PUT replay retries: transient network + 408,429,500,502,503,504.
- Begin and complete never automatically retry.
- Ambiguous complete transport failure permits **one** status GET; matching completed receipt succeeds. If GET fails, surface GET error, let next invocation resume.
- Completed sessions reuse validated receipt without duplicate complete POST.
- Empty files begin/complete with zero parts, SHA256 empty.
- Sorted, validated remote parts, receipts path/bytes/hash checked.

### Cancellation/exit/output

- SIGINT aborts, stops new scheduling, settles queued journal writes, exit130.
- Exit0 success;1 transport/server/ordinary local I/O (incl checksum/permissions);2 usage/config;3 invalid/mismatched resume state (incl session_mismatch);130 interruption.
- Each JSON object has `type` discriminator and one UUID `run_id` generated per invocation.
- Complete fields: files, bytes, uploaded_bytes, resumed_bytes.
- Byte metrics confirmed unique bytes, exclude retransmission traffic; complete reuse entirely resumed.
- Human progress stderr, final stdout.

```ts
import { setTimeout } from 'node:timers/promises';
export interface RetryOptions { retries:number; signal:AbortSignal; now?:()=>number; random?:()=>number; sleep?:(ms:number,signal:AbortSignal)=>Promise<void>; onRetry?:(attempt:number,delayMs:number)=>void; }
export function retryDelay(header:string|null,now:number):number|undefined {
  if(!header)return undefined;
  const seconds=Number(header);
  if(Number.isFinite(seconds)&&seconds>=0)return seconds*1000;
  const date=Date.parse(header);
  if(!Number.isNaN(date))return Math.max(0,date-now);
  return undefined;
}
export async function retry<T>(operation:(attempt:number)=>Promise<T>, classify:(e:unknown)=>{retry:boolean;after?:string},options:RetryOptions):Promise<T> {
  const now=options.now??Date.now, random=options.random??Math.random;
  const sleep=options.sleep??((ms,signal)=>setTimeout(ms,undefined,{signal}));
  for(let attempt=0;;attempt++) {
    options.signal.throwIfAborted();
    try {return await operation(attempt);}
    catch(error) {
      const decision=classify(error);
      if(!decision.retry||attempt>=options.retries)throw error;
      const after=retryDelay(decision.after??null,now());
      const base=Math.min(30000,500*2**attempt);
      const delay=after??Math.floor(base*(0.5+random()*0.5));
      options.onRetry?.(attempt+1,delay);
      await sleep(delay,options.signal);
    }
  }
}
```
